# Popular market examples for Glance Finance 2.3.0

Captured September 13, 2026 using the unmodified packaged Glance Finance 2.3.0 executable. Its actual widget renderer was invoked with a fresh isolated example workspace and public market data; no personal workspace was loaded.

- **widgets.png:** Apple (AAPL, green), NVIDIA (NVDA, red), Ethereum (ETH-USD, green), and Solana (SOL-USD, red), all using the five-day view. Symbols were selected to illustrate both gains and losses without changing the data or chart colors.
- **stock-chart.png:** The same Apple chart at native widget size.

Stocks show the latest five available trading sessions. Cryptocurrencies include calendar weekends. These are static public market snapshots, and stock prices may reflect a closed session. No prices or movements were fabricated.

Both images were visually reviewed before publication. They replace the featured market previews on the homepage and 2.3.0 release page; the original captures remain in the parent folder. The Home, Portfolio, and Color Settings previews remain the original 2.3.0 isolated sample-data captures.
