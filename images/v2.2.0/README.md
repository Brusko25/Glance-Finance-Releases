# Screenshot sources

Screenshots from Glance Finance 2.2.0, rendered by the installed app with sample data. Prices and transactions are illustrative; live quotes are disabled in these previews.

Captured on 2026-09-13 from the installed GlanceFinance.exe 2.2.0 with its built-in offline panel/widget renderer and isolated test artifacts.

- `widget.png`: Bitcoin chart with price and percentage change.
- `home.png`: Home panel with asset search and market categories.
- `portfolio.png`: Portfolio with an illustrative holding and transaction totals.
- `appearance.png`: Foreground palettes and widget appearance settings.
